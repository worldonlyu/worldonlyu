# Notes

This directory is yours. The chapters in `docs/` are the map; this is the territory you actually cover.

## Suggested structure

```
notes/
  00-why-i-started.md        # write this first, in your own words
  papers/                    # one file per paper, from templates/paper.md
  weekly/                    # one file per week, from templates/weekly.md
  experiments/               # logs for anything you build or run
  templates/
```

## Habits that make a research notebook worth keeping

- **Write the paper note before you finish the paper.** Summarise in your own words, then record what you did not understand. The gaps are the research agenda.
- **Separate what the authors claim from what their evidence shows.** The most useful column in a paper note is "evidence quality".
- **Tie everything back to the central question.** Every note ends with one line: what does this change about whether a mind could be emulated or transferred, and whether it would be the same mind?
- **Review weekly, not daily.** The weekly template asks what changed your mind. If the answer is "nothing" for a month, change what you are reading.
- **Date everything.** This field moves quickly; a claim without a date is a claim without context.

## Why the first note matters

Grief is a strong reason to start and a poor reason to keep going. Write down, now, why you started and what you hope to understand. In a year the reasons will have changed, and the first note will tell you how far you have come.
